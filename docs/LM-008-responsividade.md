# LM-008 — Revisão de responsividade

## Ajustes aplicados

- preservado o ajuste já existente no título principal da Home;
- criada camada responsiva global carregada depois dos estilos das páginas;
- grids principais passam para uma coluna em tablet/celular quando necessário;
- cards passam de duas colunas para uma em telas estreitas;
- ações e CTAs são empilhados no celular;
- menu mobile ganhou altura máxima e rolagem para telas baixas;
- filtros do catálogo podem rolar horizontalmente sem quebrar o layout;
- larguras mínimas dos grids foram neutralizadas para evitar overflow;
- imagens e blocos de produto receberam limites mais seguros;
- rodapé e botão flutuante foram adaptados para telas pequenas;
- tipografia dos títulos foi limitada para reduzir cortes/acento encostando.

## Larguras prioritárias para teste final

- 360 px;
- 390/412 px;
- 640 px;
- 768 px;
- 980 px;
- 1280 px;
- 1440 px ou superior.

Também validar celular em orientação paisagem.

## Páginas

- Home;
- Produtos;
- Produto individual;
- Sobre;
- Contato;
- Catálogo digital após integração da LM-018.

## Critérios

Não deve haver rolagem horizontal causada pelo layout, texto cortado, botão inacessível, menu fora da tela, imagem deformada ou CTA sobrepondo conteúdo.
